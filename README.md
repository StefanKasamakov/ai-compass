# 🧭 AI Компас

Кой AI модел за какво е и какво са скиловете за Claude и ChatGPT. Обяснено просто, на български.

**Сайт:** https://stefankasamakov.github.io/ai-kompas/

## Обновяване

Всички данни (модели, цени, задачи, скилове) са в [`data.js`](data.js). Нов модел = нов ред там. Смени и `UPDATED`.

Без build, без зависимости. Локално: `python -m http.server`, после отвори http://localhost:8000.
