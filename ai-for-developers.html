Watch out

Four rules

  1. Review everything it writes

    Treat AI code like code from a fast new colleague: read it, run the tests, and do not merge what you do not understand.

  2. Keep secrets out of prompts

    API keys and passwords in a prompt can end up in logs. Use environment variables and secret managers.

  3. Extensions run as you

    MCP servers, skills with scripts and Claude Code mods can read and change your files. Install only what you trust; check what each can reach.

  4. Watch licences

    Generated code can resemble existing code. Most tools have a setting that blocks matches with public code; turn it on for work projects.
