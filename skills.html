Agent Skills

Skills teach an agent how you work.

A skill is just a folder with instructions (and sometimes scripts) that an AI agent loads when a task matches. "Make our quarterly report", "write a proposal in our format", "test this web app": each can be a skill.

How it works

Only the label is read until needed.

  1. The agent sees names and descriptions

    Of every installed skill. That's a few lines each, so 100 skills barely cost anything.

  2. A task matches a description

    You say "turn this into a spreadsheet", it matches the xlsx skill, and only then the full SKILL.md gets loaded.

  3. It follows the recipe

    Instructions, templates, and scripts in the folder. Same result every time, in your style.

Skills are an open standard: the same folder works in Claude (app, Code, API), ChatGPT and Codex, Cursor and others.

quarterly-report/SKILL.md
quarterly-report/
├── SKILL.md       ← required
├── scripts/       ← optional code
└── templates/     ← optional files

---
name: quarterly-report
description: Builds the quarterly report from the
  sales export. Use when asked for a "quarterly
  report", "Q3 numbers" or "board update".
---
1. Ask for the sales CSV if it isn't attached.
2. Run scripts/summarize.py on it.
3. Fill templates/report.docx, keep our fonts.
4. End with 3 bullet risks, no fluff.
Don't mix them up

Skill vs MCP vs plugin vs prompt

ThingWhat it isExample
PromptA one-off instruction in the chat."Translate this to Spanish."
Project / Custom GPTStanding instructions and files for one chat space."Company assistant" with uploaded handbook
SkillKnow-how: how to do a job. Loaded only when relevant.How we write a sales proposal
MCP serverAccess: tools and data from another system.Read Gmail, write to Notion, drive a browser
PluginAn installable bundle: skills + MCP servers + commands together./plugin install document-skills@anthropic-agent-skills
Agent / subagentAn AI that works through several steps with tools on its own.Claude Code, Codex, ChatGPT agent

MCP gives hands, skills give know-how. The best setups use both: a Notion MCP server plus a skill that says how your team writes meeting notes.

Install

Adding a skill, per app

Claude Code

terminal

Official skills come as plugins:

inside Claude Code
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

Your own skill: drop the folder in ~/.claude/skills/ (every project) or .claude/skills/ (this project).

claude.ai & desktop

app

Anthropic's example skills are already built in on paid plans. For your own: Settings → Capabilities → Skills, upload the folder as a .zip.
