Vocabulary

Words you'll see everywhere

Token
A chunk of text, roughly ¾ of an English word. API pricing counts tokens in and out.
Context window
How much the model can read at once. 1M tokens is several books or a whole codebase.
Thinking / effort
How long the model reasons before answering. More effort: better answers, slower, pricier.
API
Using a model from your own code, paying per use instead of a subscription.
Open-weight
A model you can download and run yourself. Your data never leaves your machine.
Hallucination
When a model confidently makes something up. Check facts, numbers and quotes.
