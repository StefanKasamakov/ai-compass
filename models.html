Run AI on your own computer

Free, works offline, and nothing you type leaves your machine. These are smaller than Claude or ChatGPT, so expect good answers on everyday tasks rather than the very best. Tell us what computer you have and we'll show what runs well on it.

  1. Install Ollama

    A free app for Windows, Mac and Linux that downloads and runs models. Get it from ollama.com.

    Copy its command and paste it into the Terminal (Mac) or PowerShell (Windows). The first run downloads the model.

    Type your question right there, or use the Ollama app window. Prefer buttons to commands? See easy apps like LM Studio and Jan.

Vocabulary

Words you'll see everywhere

Token
A chunk of text, roughly ¾ of an English word. API pricing counts tokens in and out.
Context window
How much the model can read at once. 1M tokens is several books or a whole codebase.
Thinking / effort
How long the model reasons before answering. More effort: better answers, slower, pricier.
API
Using a model from your own code, paying per use instead of a subscription.
Open-weight
A model you can download and run yourself. Your data never leaves your machine.
Hallucination
When a model confidently makes something up. Check facts, numbers and quotes.
