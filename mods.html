Claude Code mods

Mods change how Claude Code looks and works.

Since October 2026, Claude Code can be extended with mods: small programs that add panes, meters, buttons, games and safety checks to the coding assistant, or change how it behaves. Here is what they are, the well-known ones, and what each one can reach on your computer.

The idea

What a mod is

A skill changes what Claude knows. A mod changes Claude Code itself.

A mod is a plugin written in JavaScript or TypeScript that runs inside Claude Code. It is called when something happens: Claude is about to run a tool, you send a message, or part of the screen is drawn. It can watch that moment, change it, or take it over.

Draw on screen
A pane beside the conversation, a band above the prompt, buttons and text fields: usage meters, agent dashboards, previews, even small games.
Restyle Claude Code
Change how tool rows, the spinner or Claude's replies look. The permission prompt is the one thing a mod cannot restyle.
Step into an action
Hold a risky command until you confirm it, hide secrets before the model reads them, or send one request to another model.
Add commands
A /command that runs at once, even while Claude is busy, without starting a new answer.
Where they work. Claude Code 2.1.287 or later, in the terminal and in the Code tab of the Claude desktop app. In the VS Code chat panel, claude -p and cloud sessions a mod still runs, but nothing it draws is shown.

Install

Add a mod in three steps

Mods install like any Claude Code plugin. Each mod's page in the directory gives its exact commands.

  1. Add the author's marketplace

    Inside Claude Code, type /plugin marketplace add owner/repo with the GitHub name of the mod's repository.

  2. Install the mod

    Type /plugin install name@marketplace. To only try it once, start Claude Code with claude --plugin-dir ./path-to-the-mod instead.

  3. Load it

    Run /reload-plugins, or restart Claude Code. /plugin shows a line such as "1 mod active".

Switching mods off

  • One mod: disable or uninstall it in /plugin, tab Installed.
  • All mods for one session: start with claude --safe-mode.
  • All mods, always: set "disableAllHooks": true in ~/.claude/settings.json.
Before you install

A mod runs as you

Mods are not sandboxed. Install them only from authors you trust.

Once loaded, a mod can do anything your user account can:

  • Read and change files anywhere you can, and start programs
  • Read your environment variables and settings, including API keys
  • See every prompt you send and every action Claude takes
  • Approve an action before you are asked, or send a message as if you typed it
  • Use the internet, and spend your plan's usage by calling a model

Check one in a minute

Download the mod's folder, then ask Claude Code's own validator what it does, without running it. The hooks: and calls: lines list what it listens to and what it asks for.

Our access labels (Only draws, Reads, Writes or runs, Uses the internet) come from that same check, run on every mod in the list. A mod that only draws is the safest kind to try first.
