How it works

Points, votes, and why GitHub

Every tool has a "Vote:" issue in our GitHub repo. A 👍 reaction there is your vote. Signing in with GitHub keeps it one vote per person and stops bots, and there's no extra account to make.

Vote on GitHub Suggest a tool

  1. +1 point per vote

    React 👍 on a tool's vote issue. Vote for as many as you genuinely use.

  2. +2 per repo explained

    Confused by a repo? Ask the agent to explain it. It replies on the issue and adds it to the Repo Explainer.

  3. +10 per accepted tool

    Suggest a skill or MCP server we're missing with the form. If it's accepted, it joins the site and you get the points.

  4. +5 per merged fix

    Spotted an outdated price or a broken link? Edit the JSON in data/ and open a pull request.
